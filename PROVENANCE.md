# Provenance and verification

BetterLKFrames is an original implementation. No BetterBlizzFrames code/artwork or Blizzard client assets are bundled. Media files are original procedural grayscale/alpha textures generated by tools/generate-assets.py and coloured at runtime. The Lua code references installed client art by path where appropriate.

## Reference sources

- Feature inspiration: [BetterBlizzFrames](https://github.com/Bodify/BetterBlizzFrames), commit `dfd57fe090d984a24993d6233940e015489d79a3`. Its All Rights Reserved license was reviewed; no source/assets were copied into this project.
- Legacy API/frame reference: [3.3.5 interface files](https://github.com/wowgaming/3.3.5-interface-files), commit `d0339b17b0221db76e6acd2dc2915d224a5b62ca`. Reviewed frame names, cast/channel signatures, aura indices/cooldowns, native power events, label ownership and decorative texture declarations. No mirror files/assets are distributed here.

## Tests

The committed tests use Lupa 2.6's **Lua 5.1** runtime and an explicit mock of legacy client APIs. They cover defaults/settings, missing optional frames, bar styling/restoration, combat deferral, movement/snapping/grid, casts/channels, stable aura polling, character/account isolation, limited aura offsets and window-border scope. All **115 assertions** passed for the current implementation.

Seven Lua sources are syntax-checked; package validation checks Interface 30300/TOC load order, original TGA dimensions/alpha/gradient properties, unchanged cast-data behaviour, secret patterns, ZIP content/CRC and SHA256. Research checkouts, dependencies, private operational reports, generated logs and historical archives are not part of the maintained repository or installable package.

These checks do not establish actual game rendering, secure execution/taint safety or all interactions with custom clients/other addons. In-game validation remains required. The README records reported defects and the practical checklist; no screenshots are presented as automated in-game proof.

The public project files contain no server configuration, account data, saved settings, private credentials or machine-specific operational paths. Review every commit: automated patterns reduce mistakes but cannot prove all prose is free of personal information.
